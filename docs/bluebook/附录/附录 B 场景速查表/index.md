# 附录 B 场景速查表

> 内容来源：WorkBuddy 官方指南（非官方整理，© 本指南作者，保留所有权利）

## 这份附录是干什么的

前面 28 章按"功能"和"案例"组织，你得记住某个功能在哪一章。这份附录反过来——**按你想干的事查**。

用法只有一句：**在左边找到你卡住的那件事，右边直接看该开什么、去哪一章。**

## 一、按场景查（我要干 X，该用什么）

### 办公三件套

| 我要做的事 | 用什么 | 详见 |
|---|---|---|
| 写一份正式文档/报告 | `docx`（Word 生成）或 `tencent-docx`（排版美化） | 第 11 章 |
| 改一份已有的 Word | `tencent-local-office-edit`（实时读写本机文件） | 第 11 章 |
| 做表格、算数据、透视 | `xlsx` 或 `tencent-docs-sheet-generation`（新建）/ `sheetagent`（处理已有表） | 第 11 章 |
| 做 PPT | `pptx` 或 `tencent-pptx` | 第 11 章 |
| 三件套一起要 | 同一任务里分三步交付，先文档再表格再 PPT | 第 11 章 |

### 文件与整理

| 我要做的事 | 用什么 | 详见 |
|---|---|---|
| 整理乱糟糟的桌面/文件夹 | 文件整理 + 用附录 A 模板 4（拆步骤） | 第 12 章 |

| 从一堆资料里提炼要点 | 给上下文 + 分批处理（模板 3、4） | 第 12、16 章 |

### 浏览器与自动化

| 我要做的事 | 用什么 | 详见 |
|---|---|---|

| 让它定时抓某个网页更新 | 浏览器自动化 + 定时任务 | 第 10、15 章 |
| 用网页做测试/截图 | `playwright-cli` | 第 13 章 |

### 资讯与知识管理

| 我要做的事 | 用什么 | 详见 |

| 每天汇总资讯成一份简报 | RSS/抓取 + 定时任务 + 推送 | 第 15 章 |

### 内容创作与多媒体

### 进阶系统

### 岗位与行业

## 三、按卡点查（我是什么状态）

| 我的状态 | 怎么办 | 详见 |
|---|---|---|
| 打开软件不知道从哪开始 | 从第 4 章"第一个任务"开始 | 第 4 章 |
| 界面太乱找不到功能 | 导航栏 / 自定义菜单 | 第 3 章 |
| AI 说"它什么都能做"，结果做不到 | 预期误区 + 五问定标 | 第 1 章、附录 A 模板 1 |
| AI 把它该我的活也干了 | 权限模式 / 权限边界三条 | 第 7、10 章 |
| AI 编了一个不存在的功能 | 检查是不是把 Skill 想象得太全能；用 `find-skills` 找现成的 | 第 1、5 章 |
| 任务卡在"待确认"不动 | 它在等你回话 | 第 3 章 |
| 跑完看不出好坏 | 验收标准（附录 A 模板 5） | 附录 A |
| 改了文件不敢放心 | 变更 Diff + 先备份 | 第 3 章、附录 A 模板 7 |
| 定时任务跑久了会乱 | 可靠性三原则 + 心跳对账 | 第 25 章 |
| 授权的连接器想关掉 | 停止使用 vs 解绑 | 第 7 章 |
| 密钥/token 泄露了 | 撤销连接器 + 换密钥 | 第 7、9 章 |
