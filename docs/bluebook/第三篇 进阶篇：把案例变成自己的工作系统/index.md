# 本篇导读 · 第三篇 进阶篇：把案例变成自己的工作系统

> 内容来源：WorkBuddy 官方指南与社区实战案例整理（非官方，© 本指南作者，保留所有权利）

<Paywall part="3" variant="banner" />

第二篇的 11 个案例，你跑通任何一个，都会经历同一种感觉：**第一次惊喜，第二次顺手，
第三次开始嫌重复**——"这类活我好像每次都在说同样的话"。

这个"嫌重复"，恰恰是进阶的信号。第三篇要解决的就是它：**把零散的成功，沉淀成
可复用、可协作、可靠的 AI 工作系统**。学完本篇，你手里的不再是"一堆会用的功能"，
而是一台能持续运转的机器。

## 本篇的三层结构

| 章节 | 解决什么 | 一句话概括 |
|-|-|-|
| 第 22 章 · 打造 Skill | **复用层**：方法论怎么固化 | 把书、视频、你自己的经验，蒸馏成一招即来的专属技能 |
| 第 23 章 · 实操案例集 | **弹药层**：还有哪些组合可用 | 邮件、浏览器自动化、数据分析、多模态……按需取用 |
| 第 24 章 · 多 Agent 设计 | **协作层**：一个对话干不动的活怎么办 | 把"全能助手"升级成"分工明确的项目团队" |
| 第 25 章 · 自动化可靠性 | **稳定层**：怎么让它每周自己跑不出事 | 自动化跑通一次是运气，跑一百次不出事才是系统 |

## 读本篇之前，你该有的基础

- 第一篇：会用对话、装技能、连 MCP、建自动化（第 1–10 章）；
- 第二篇：至少完整跑通过 2–3 个案例，体会过"五问定标 + 选 Skill + 提示词 + 验收"
  的完整节奏；
- 一个你自己的"重复活清单"：哪些事你每周都在重复？本篇结束时，它就是你的
  自动化改造对象。

> 如果你还没跑过第二篇的案例，建议先回去跑一个。第三篇的所有方法，
> 都是踩在"真实跑通过一次"的地基上的——没有地基，固化出来的只是空架子。

## 本篇贯穿的一条主线

和第二篇一样，本篇继续贯彻**零成本思路**：

1. **先用免费的现成技能跑通**（find-skills 帮你配装）；
2. **跑顺了的活，用 skill-creator 固化成专属技能**（第 22 章）；
3. **一个人干不动的，拆成多 Agent 协作**（第 24 章）；
4. **每周都要干的，交给自动化，并按可靠性清单加固**（第 25 章）。

四步走完，你就完成了从"用户"到"系统Owner"的转变——这也是第四篇"岗位与行业
落地"的前提：先有自己的系统，才谈得上把它变成职业竞争力。

## 本篇任务总清单

- [ ] 把至少 1 本书或 1 套视频课蒸馏成 1 个专属 Skill（第 22 章）
- [ ] 从第 23 章案例集中挑 2 个组合，装进自己的工具箱
- [ ] 用多 Agent 架构跑通 1 条内容生产流水线（第 24 章）
- [ ] 把 1 个手动重复活升级为带失败通知的每周自动化（第 25 章）
- [ ] 建立自己的"每周对账"习惯：自动化跑了几次、成功几次、产物在哪
