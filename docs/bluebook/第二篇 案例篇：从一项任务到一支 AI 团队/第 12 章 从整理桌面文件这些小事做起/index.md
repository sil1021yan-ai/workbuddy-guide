# 第 12 章 从整理桌面文件这些小事做起

> 内容来源：WorkBuddy 官方指南与社区实战案例整理（非官方，© 本指南作者，保留所有权利）

<Paywall part="2" variant="banner" />

桌面乱成垃圾场、下载文件夹塞了几百个无名文件——这种"小事"最消耗心力，
却最容易被一直拖着。WorkBuddy 能直接操作你电脑上的文件，把它当成保洁：
批量重命名、按类型归档、找重复、挑大文件。**但动文件有风险**，这一章重点教
你安全地让它干，并把整理规则固化成零成本技能。

![一只小黑蹲在一堆散落的文件前，用双手把文件摞整齐](./images/01-file-tidy.png)

*配图为示意插画，用于帮助理解"整理文件"，与实际软件界面无关。*

## 一、先想清楚：这次整理要交付什么

| 问题 | 要说清什么 | 示例 |
|-|-|-|
| 目标 | 整理完要什么状态 | 桌面只留常用，其余按类型归档、能按名找到 |
| 受众 | 谁会用这些文件 | 主要是你自己，可能涉及家人/同事共享目录 |
| 材料 | 哪些文件参与整理 | 仅"下载""桌面"两个文件夹，不碰工作盘 |
| 格式 | 整理后的目录结构 | 按"类型 / 年月"两级目录 |
| 验收 | 怎么判断整理成功 | 原文件无丢失、备份存在、命名规则一致 |

## 二、先选对 Skill：文件整理的组合

WorkBuddy 整理本地文件，本质是 **Agent 模式下的本地文件操作能力**，不一定需要
单独技能；但配合下面这些更稳：

| 方式 / Skill | 适合处理 | 本章怎么用 | 注意点 |
|-|-|-|-|
| **通用 Agent（本地文件操作）** | 重命名、移动、归档、查找 | 直接下指令让它操作指定目录 | 必须开启权限确认，永远先预览后执行 |
| **手动复制 / 备份** | 整理前的安全网 | 先把待整理目录复制一份到备份 | 不可逆操作前必做 |
| **Browser Automation** | 网盘 / 网页端文件整理 | 整理云盘里的散文件 | 需要账号授权，注意隐私 |
| **skill-creator（零成本）** | 把整理规则固化 | "每周整理下载文件夹"做成技能 | 跑顺后固化，下次一句话触发 |

> 铁律：动文件的指令，**认准官方源、不开全自动批准**。AI 很听指令，但"删/移"
> 是不可逆的，这道闸得你守。
