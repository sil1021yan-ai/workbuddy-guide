# 第 14 章 生活助手的价值，是减少琐碎

> 内容来源：WorkBuddy 官方指南与社区实战案例整理（非官方，© 本指南作者，保留所有权利）

工作之外，生活里有一大堆"不起眼但费神"的小事：查攻略、拟一段话、算个账、记个
提醒。WorkBuddy 当生活助理，价值不在"多厉害"，而在**把琐碎接住**，让你把注意力
留给重要的事。它擅长"给方案"，不擅长"替你负责"——这一章教你把它用对位置。

![一只小黑举着一张写满待办的小纸条，另一只手把琐事一件件摁进一个收纳盒](./images/01-life-assistant.png)

*配图为示意插画，用于帮助理解"生活助手"，与实际软件界面无关。*

## 一、先想清楚：这次要它帮什么

| 问题 | 要说清什么 | 示例 |
|-|-|-|
| 目标 | 解决哪件琐事 | 规划周末杭州两日游，轻松不赶 |
| 受众 | 谁用这个方案 | 我和伴侣，带老人 |
| 材料 | 你已有的偏好/约束 | 预算 2000、不爱排队、住西湖边 |
| 格式 | 要清单、行程表还是一段话 | 按天的时间表 + 备选 |
| 验收 | 怎么判断可用 | 时间衔接合理、预算不超、有备选 |

## 二、先选对 Skill：生活助手的组合

| 方式 / Skill | 适合处理 | 本章怎么用 | 注意点 |
|-|-|-|-|
| **通用 Agent（对话/参谋）** | 攻略、拟稿、算账、比价 | 随叫随答，给选项和理由 | 决策权在你 |
| **日历 / 提醒连接器** | 提醒、待办真正生效 | 接上系统日历/待办后，提醒才落地 | 接法见第一篇第 7 章 |
| **腾讯文档 / kdocs** | 把清单、心愿单存成可共享 | 旅行清单、购物清单和家人同步 | 需授权 |
| **find-skills** | 找更专业的技能 | "有没有记账/菜谱技能" | 零成本入口 |

## 三、真实可复制提示词

### 提示词 1｜出行攻略（带约束）

```text
帮我规划【杭州】两日游，时间【本周末】，同行【我和伴侣+一位老人】。
约束：总预算约 2000 元、不爱排队、住宿想在西湖边、节奏轻松不赶。
输出按天的时间表：时间段、去哪、吃什么、交通方式、预计花费，并给每个时段一个备选方案。
```

### 提示词 2｜拟一段不好开口的话

```text
帮我写一条微信，委婉拒绝朋友这周末的饭局，理由是最近加班走不开，
但表达下周末再约的诚意。语气轻松、不刻意、30 字以内。
```

### 提示词 3｜礼物参谋

```text
我想给妈妈挑生日礼物，预算 300 内，她喜欢园艺和喝茶。
给我 5 个选项，每个选项写清：是什么、大概价格、为什么适合她、哪里能买。
最后告诉我如果只能选一个，你推荐哪个及理由。
```

### 提示词 4｜算账（多人）

```text
三人 AA 聚餐，总计 386 元，其中 A 多付了饮料 28 元。
请算清楚：每人应付多少、A 实际多付了多少、其他两人该补给 A 多少。
```

## 四、执行步骤表

| 步骤 | WorkBuddy 做什么 | 你要确认什么 |
|-|-|-|
| 1 | 给约束，出方案/选项 | 方案是否符合你的真实情况 |
| 2 | 你选，它细化 | 细节（价格/时间）是否靠谱 |
| 3 | 存清单/设提醒（接连接器后） | 提醒是否真落地 |

## 五、和生活助手相处的分寸

**参谋 vs 裁判**：它给选项和依据（参谋），最终决定权在你（裁判）。涉及人际关系、
花钱、健康的事，把它当参考，别当裁判——尤其是健康建议，以专业人士为准。

## 六、零成本 Skill：把常用参谋固化

跑顺提示词 3（礼物参谋）这类反复用的，用 `skill-creator` 固化：

```text
帮我做一个"送礼参谋"技能：输入对象、关系、预算、喜好，输出 5 个带价格和理由的选项
并给首选推荐。触发词：送什么、礼物参谋。
```

## 七、实际效果与验收标准

**实际效果**：你拿到一份能照走的方案、一段能直接发的文字、一笔算清的账。

**验收标准**：

- [ ] 方案/文字/数字符合你的约束（预算、语气、算法对得上）
- [ ] 涉及健康/重大花钱的决定，你保留了最终判断
- [ ] 隐私信息（地址/身份证/家人）没有写进任务里

## 小白说明书

> **生活助理**：把 AI 用在个人日常琐事上，帮你规划、拟稿、计算、提醒。
>
> **参谋 vs 裁判**：AI 给选项和依据（参谋），最终决定权在你（裁判）。
>
> **零成本 Skill**：用 skill-creator 把反复用的参谋类需求固化成专属技能。
