# 第 16 章 收藏不是知识管理，能再次用起来才是

> 内容来源：WorkBuddy 官方指南与社区实战案例整理（非官方，© 本指南作者，保留所有权利）

收藏 = 安慰自己"以后会看"，结果再也没打开。真正的知识管理是：**存得进，更找得回、
用得上**。这一章教你用 WorkBuddy 把收藏变成能复用的资产——核心是"存时摘要+打标签，
用时检索，复用产出"。

![一只小黑把一张张收藏的纸条贴到一面墙上，墙边立着标签和检索框](./images/01-knowledge.png)

*配图为示意插画，用于帮助理解"知识管理"，与实际软件界面无关。*

## 一、先想清楚：这次知识管理要交付什么

| 问题 | 要说清什么 | 示例 |
|-|-|-|
| 目标 | 让收藏能"下次用上" | 关于定投的资料，下次能一句话调出 |
| 受众 | 谁用 | 主要是未来的我自己 |
| 材料 | 哪些内容进库 | 文章/笔记/截图，非机密 |
| 格式 | 库的结构 | 每篇：摘要+固定标签+原文链接 |
| 验收 | 怎么判断有用 | 我能搜到、能基于它产出新东西 |

## 二、先选对 Skill：知识管理的组合

| 方式 / Skill | 适合处理 | 本章怎么用 | 注意点 |
|-|-|-|-|
| **资料库类连接器** | 跨设备、可协作的知识库 | 云端存+检索，适合常协作 | 见第一篇第 7 章 |
| **腾讯文档 / kdocs** | 在线笔记沉淀 | 建"我的知识库"文档树 | 需授权 |
| **本地 Markdown / 工作区** | 电脑上的笔记文件 | AI 直接读，隐私更稳 | 见第一篇第 3 章 |
| **find-skills** | 找更专业的知识管理技能 | 如"文献管理""读书笔记" | 零成本入口 |

## 三、真实可复制提示词

### 提示词 1｜存的时候，摘要 + 打固定标签

```text
把这篇文章存进我的知识库，写 3 句摘要，从我的固定标签集合
【投资/写作/工具/健康/职场/法律】里选 1–3 个贴上，并记下原文链接和存入日期。
不要自创标签。
```

### 提示词 2｜用的时候，直接问"我存过什么"

```text
我之前存过关于【定投】的资料吗？如果有，把每篇的摘要和原文位置告诉我，
并总结这些资料里关于"定投频率"的一致结论和分歧点。
```

### 提示词 3｜复用的时候，基于库存产出

```text
根据我知识库里关于【定投】的内容，帮我写一段发在朋友圈的科普（150 字以内，
口语、不劝投、注明"个人整理非建议"），并列出引用的那几篇原文。
```

## 四、执行步骤表

| 步骤 | WorkBuddy 做什么 | 你要确认什么 |
|-|-|-|
| 1 | 收到内容，摘要+选固定标签+存库 | 标签在你的固定集合内、摘要准确 |
| 2 | 你检索"我存过 XX 吗" | 它真能找回、定位准确 |
| 3 | 基于库存产出新内容 | 引用了真实存过的原文 |

## 五、两种"仓库"怎么选

- **本地笔记/文件**：你电脑上的 Markdown、文档，AI 能直接读（配合工作区，见第一篇第 3 章），隐私更稳
- **云端知识库**：跨设备、可协作（资料库类连接器，见第一篇第 7 章）

怕丢就本地+云端双份；常协作就云端为主。

## 六、零成本 Skill：把"收藏即摘要"固化

跑顺提示词 1 后，用 `skill-creator` 固化成"存入即摘要"技能：以后任何新链接/文章
丢给它，自动按你的固定标签集摘要入库，不用每次写长提示词。

## 七、实际效果与验收标准

**实际效果**：你的收藏从"死库存"变成"活资产"——能搜到、能复用。

**验收标准**：

- [ ] 存的内容都有摘要 + 固定标签 + 原文位置
- [ ] 检索"我存过 XX 吗"能准确找回
- [ ] 标签严格在你的固定集合内（没冒出搜不到的词）

## 八、一个必须记住的坑

**标签要你定，别全扔给 AI 自由发挥**。否则它会打出一堆你下次搜不到的词。定 5–10 个
常用固定标签（如 投资/写作/工具/健康），让 AI 在固定集合里选，检索才稳。

## 小白说明书

> **知识库**：集中存放你收集的信息，并能被 AI 检索、引用的"个人图书馆"。
>
> **标签（Tag）**：给内容贴的归类词，是以后能快速找回的关键。固定集合比自由发挥可靠。
>
> **复用**：不是"再看一遍"，而是把旧内容当素材，让 AI 产出新东西。
>
> **零成本 Skill**：用 skill-creator 把"存入即摘要"固化成专属技能。

- [ ] 给自己定 5–10 个固定标签词，以后统一用
