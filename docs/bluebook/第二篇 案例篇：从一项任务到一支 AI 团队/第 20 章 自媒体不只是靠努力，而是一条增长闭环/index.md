# 第 20 章 自媒体不只是靠努力，而是一条增长闭环

> 内容来源：WorkBuddy 官方指南与社区实战案例整理（非官方，© 本指南作者，保留所有权利）

<Paywall part="2" variant="banner" />

很多人做自媒体卡在"又写又剪又发又看数据"，精力全耗在重复劳动，最后断更。这一章
把自媒体拆成一条**闭环**：选题 → 生产 → 发布 → 看数据 → 反哺选题。WorkBuddy 能在
每一环替你省时间，让"坚持"变得不那么累——关键不是单次爆款，而是**每周稳定转一圈**。

![一只小黑推着一个首尾相接的环在走，环上标着 选题-生产-发布-数据](./images/01-growth-loop.png)

*配图为示意插画，用于帮助理解"增长闭环"，与实际软件界面无关。*

## 一、先想清楚：这条闭环要交付什么

| 问题 | 要说清什么 | 示例 |
|-|-|-|
| 目标 | 做自媒体为了什么 | 建立个人影响力、引流到私域 |
| 受众 | 谁看 | 对 AI 感兴趣的小白 |
| 材料 | 你已有的素材/账号 | 过往爆款、行业知识 |
| 格式 | 内容形态 | 短视频为主、图文为辅 |
| 验收 | 怎么判断转得好 | 每周稳定更新、涨粉结构改善 |

## 二、先选对 Skill：自媒体闭环的组合

| 方式 / Skill | 适合处理 | 本章怎么用 | 注意点 |
|-|-|-|-|
| **选题 / 内容分析技能** | 列热点、做差异化、评分 | 选题环节提效 | 结果当参考，不盲跟 |
| **写作 / 排版技能** | 写稿、配图、排版 | 生产环节（见第 11 章） | 事实与口吻你把关 |
| **视频生成（第 19 章）** | 出短视频草稿 | 生产环节 | 生成后人工过一遍 |
| **数据 / 后台技能** | 读后台、找涨跌原因 | 数据环节 | 注意账号安全 |
| **自动化（第一篇第 10 章）** | 每周自动复盘 | 把"看数据"无人化 | 配合推送 |
