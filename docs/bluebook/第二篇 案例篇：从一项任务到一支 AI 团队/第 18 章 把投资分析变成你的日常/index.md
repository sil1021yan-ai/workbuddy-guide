# 第 18 章 把投资分析变成你的日常

> 内容来源：WorkBuddy 官方指南与社区实战案例整理（非官方，© 本指南作者，保留所有权利）

> ⚠️ 本章只讲"怎么用 AI 辅助做研究整理"，**不构成任何投资建议**。
> 投资决策和盈亏责任永远在你自己。

投资本身就是一件**高度信息密集、强结构化、又极度依赖判断**的事：读不完的财报、
理不清的行业、吵不停的多空。而整理碎片信息、拆解复杂材料、把思考过程摆到台面上，
恰好是 AI 擅长的。这一章讲清楚：在一次完整的股票/标的研究里，AI 到底能替你做掉
哪些低质量的重复劳动，把精力还给判断本身。

## 一、先想清楚：AI 在投资里该干什么

多数人对"AI 炒股"的想象是让它预测涨跌。但从真实的高频用法看，绝大多数有价值的
提示词其实只集中在四类事上：**读不完的财报帮我总结；行业太复杂帮我理逻辑；
市场吵太凶帮我把多空放进一张表；我怕自嗨帮我校找反证。** 这四类都不是"预测涨跌"，
而是**减少低质量思考的时间**。AI 最合理的位置，是一个不知疲倦、不带情绪、随叫随到
的研究助理——它负责把事实底座打牢，把判断留给你。

动手前先用五问定标：

| 问题 | 要说清什么 | 示例 |
|-|-|-|
| 目标 | 这次研究支撑什么决定 | 判断是否把某只票纳入观察池，还是当下加减仓 |
| 标的 | 具体哪家公司/行业 | 天孚通信（300394），光通信/CPO 板块 |
| 材料 | 哪些是事实来源、哪些只是参考 | 年报、三季报、券商研报是事实；股吧观点只作情绪参考 |
| 深度 | 只要事实梳理，还是要到估值和多空推演 | 先做事实底座（Prompt 1–3），再上尽调级（Prompt 6） |
| 验收 | 怎么判断结果可用 | 每个判断能追到数据来源，事实与观点分开标注 |

## 二、先选对 Skill：金融场景的组合

| Skill 名称 | 适合处理 | 本章怎么用 | 注意点 |
|-|-|-|-|
| **stock-advisor** | 单只股票端到端分析 | 上传截图或给代码，自动跑技术面/基本面/交叉验证/排版 | 本章主线 |
| **a-share-analyst** | A 股日常行情与选股 | 实时行情、技术指标、量化选股、每日报告 | 偏日常盯盘与批量筛选 |
| **financial-expert** | 金融数据查询与筛选 | 选股、基金筛选、财务指标、宏观/行业时序、研报检索 | 依赖数据源 MCP，需先配置 |
| **peers-advisory-group** | 多视角决策讨论 | 四位"幕僚"围绕一个议题交叉辩论 | 被 stock-advisor 作为决策模块调用 |

> 搭配思路：**日常盯盘和批量选股用 `a-share-analyst` 与 `financial-expert`；要对一只
> 票下深功夫、出完整报告，用 `stock-advisor`；需要跳出单一视角、逼自己看反面时，
> 叫上 `peers-advisory-group`。** Skill 以 SkillHub 实际上线为准，装前认准官方源。

## 三、从查资料到下判断：一套可复用的研究提示词链路

这一节是纯提示词，按"最简单 → 相对复杂"排列，覆盖从"查资料"到"下判断"的完整链路。
你不必每条都用——先用前三条建立事实底座，需要深挖时再往后走。第 6 条是把前面所有
环节压进一个框架的"全家桶"，也是日常在各类 DeepResearch 里最常用的一条。

> 用法统一：把方括号 `【】` 里的占位换成你的标的，粘贴运行即可。每条都强调
> "只使用可核实信息、事实与判断分开"，这是防止 AI 编数字的关键。

### Prompt 1｜最基础：给公司建一个"事实底座"

```markdown
请帮我系统梳理【XXX 公司】的基础情况，输出结构化总结，包括：
1）核心业务与主要产品线
2）收入与利润来源构成
3）主要客户与应用场景
4）公司在产业链中的位置
5）近几年最重要的战略变化

## 要求：
- 只使用可核实的信息
- 每一部分用 3–5 条要点说明
- 不做投资建议，只做事实整理
```

### Prompt 2｜行业视角：这是不是一个"好行业"

```markdown
请从行业研究的角度，分析【XXX 公司】所在的【XXX 行业】：
1）行业所处的周期阶段（复苏/扩张/衰退/萧条）
2）供需关系与主要驱动因素（产能、开工率、库存、订单/交付周期）
3）价格变化机制与历史波动（价差、成本传导、Capex 趋势、扩产项目）
4）行业集中度与竞争格局
5）影响行业的关键外部变量（政策、技术、宏观）

请明确指出：哪些是长期结构性因素，哪些是短期波动因素。
输出：周期阶段判断 + 关键证据图表清单 + 领先指标(3个)与滞后指标(3个)。
```

### Prompt 3｜业务拆解：钱到底是怎么赚来的

```markdown
请你以【价值投资/基本面研究】视角，对【XXX 公司】进行"业务拆解"，目标是回答：
这家公司【真正、长期】是靠什么赚钱的？

## 要求
- 仅基于可验证信息（年报、招股书、定期公告、投资者交流纪要、权威行业报告）
- 明确区分【事实】与【判断】，所有判断必须给出证据或逻辑链
- 输出为 Markdown 结构化报告

## 必答结构
一、公司"赚钱方式"的一句话结论（卖什么 → 卖给谁 → 为什么能赚钱）
二、业务结构全拆解（必须量化：收入占比、毛利率、增长趋势）
三、赚钱机制拆解（钱怎么收、成本花哪、毛利率由什么决定、是否规模效应）
四、客户、渠道与定价权（是否集中、能否提价、切换成本）
五、子公司/非经常性业务（利润来自经营、周期还是补贴/处置）
六、商业模式的"稳定性与脆弱点"（哪些假设被破坏逻辑就失效）
```

### Prompt 4｜多空对比：把吵架放进一张表

```markdown
围绕【XXX 公司】，分别整理"看多"和"看空"两方的核心论点，输出对比表：
列：论点、支撑证据、反驳点、可信度(高/中/低)。
要求：两方证据都来自可核实来源，不预设立场，最后让我自己判断。
```

### Prompt 5｜反证：逼自己看反面（防自嗨）

```markdown
我当前倾向于看好【XXX 公司】，理由是【简述我的理由】。
请扮演"最严厉的反对者"，找出能证伪我观点的 3–5 个证据或逻辑漏洞，
并说明：哪些情况下我的看多逻辑会失效。不要安慰我。
```

### Prompt 6｜全家桶：把前面压成一个研究框架

```markdown
请对【XXX 公司】做一次完整研究，综合以下功能：
事实底座（业务/财务/产业链）+ 行业周期 + 业务拆解 + 多空对比 + 反证。
输出一份结构化研究报告，包含：一句话结论、关键事实表（附来源）、核心风险、
多空分歧、以及"仍需我亲自核实"的清单。
全程区分事实与观点，不做买卖建议。
```

## 四、执行步骤表

| 步骤 | WorkBuddy 做什么 | 你要确认什么 |
|-|-|-|
| 1 | 跑 Prompt 1–3 建事实底座 | 数据有来源、没编 |
| 2 | 跑 Prompt 4–5 看多空与反证 | 反面观点没被忽略 |
| 3 | 跑 Prompt 6 出完整报告 | 结论里"待核实"项你真去核了 |
| 4 | 你基于报告下判断 | 决策权始终在你 |

## 五、实际效果与验收标准

**实际效果**：一份结构清晰、事实与观点分开、每个判断能追到来源的研究报告，而不是
一句"建议买入"。

**验收标准**：

- [ ] 每条关键数据都标了来源或"待核实"
- [ ] 事实与观点明确分开，没有把 AI 的推测当成事实
- [ ] 多空都覆盖，你没有只看到想看的
- [ ] 报告末尾的"待核实"清单，你抽样核对过

## 六、零成本 Skill：把"事实底座"固化

Prompt 1 这种"每周都要对某只票做事实梳理"的需求，用 `skill-creator` 固化：以后只说
"拉一下【XX公司】的事实底座"，它就按固定结构出报告，不用每次粘贴长提示词。

## 七、一个必须记住的坑

**数字必须可核实。** 让它每条关键数据标来源、标"待核实"，你再抽样核对。市场传闻、
过时数据、它"自信地编"，是三类最常见的坑。AI 给的"明确买卖建议"不是它的职责，
也别照单全收——**它出材料，你做判断。**

## 小白说明书

> **财报**：公司定期公布的"成绩单"，含营收、利润、现金流等。
>
> **维度对比**：你先定好从哪几个方面比（如营收/利润），对比才不乱。
>
> **待核实**：AI 对拿不准的数据打的标记，提醒你亲自核对再信。
>
> **事实底座**：把一家公司/行业的可核实事实先系统梳理清楚，再做判断的地基。
>
> **零成本 Skill**：用 skill-creator 把周常研究固化成专属技能。
