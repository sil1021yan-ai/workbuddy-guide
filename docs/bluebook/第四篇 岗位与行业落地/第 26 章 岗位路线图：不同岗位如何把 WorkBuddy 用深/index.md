同一个工具，运营拿来做活动策划，HR 拿来写 JD，产品经理拿来整理用户反馈——
**岗位决定你的高频任务，高频任务决定你该装什么技能、固化什么 Skill**。

这一章给 6 个常见岗位各画一张路线图：入门任务（第一周）→ 高频组合（第一个月）
→ 固化方向（第三个月）。找到你的岗位，按图施工。

*配图为示意插画，用于帮助理解本章主题，与实际软件界面无关。*

## 一、新媒体运营

| 阶段 | 做什么 |
|-|-|
| 第 1 周 | 用第二篇第 20 章的选题评分表，把本周选题定下来 |
| 第 1 个月 | 选题 → 初稿 → 封面图 → 排版，四道工序跑顺（第 19、20 章 + 多模态案例） |
| 第 3 个月 | 固化"我的风格写作 Skill"；选题库 + 数据复盘每周自动化 |

**岗位专属提示词｜爆款结构逆向**

```text
分析我们账号最近 20 篇笔记的数据（posts-data.xlsx）：
1. 找出互动率 TOP5 和 BOTTOM5，对比它们的：标题句式、首图类型、开头 3 句、
   发布时间；
2. 总结 3 条"我们账号的爆款规律"和 3 条"踩雷规律"；
3. 用这两组规律给下周 5 个候选选题打分排序。
```
