## 一、先转变视角：你不是用户，你是管理者

| 用户思维 | 管理者思维 |
|-|-|
| "让 AI 帮我写" | "写作岗的产出标准是什么，谁来验" |
| "这个对话聊崩了，重来" | "岗位说明书没写清楚，回去改 SOP" |
| "我忙不过来了" | "哪个环节产能不足，是加人还是加自动化" |
| "这个功能真好玩" | "这个能力归到哪个岗位，怎么考核" |

管理者不看单次成败，看**系统的产能和质量**。这一章的全部内容，
就是把管理者思维变成可执行的编制表。
