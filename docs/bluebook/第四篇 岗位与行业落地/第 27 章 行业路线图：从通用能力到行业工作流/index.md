# 第 27 章 行业路线图：从通用能力到行业工作流

> 内容来源：WorkBuddy 官方指南与社区实战案例整理（非官方，© 本指南作者，保留所有权利）

<Paywall part="4" variant="banner" />

会用工具的人很多，**懂行业的会用工具的人很少**。"帮我写个文案"谁都会；
"按教培行业招生季的节奏写招生文案"——这才值钱。

这一章讲透一个公式：**通用能力（前三篇）× 行业知识库 = 行业工作流**，
并用两个行业完整示范怎么把这个公式落地。

![一只小黑把刻着行业图标的积木垒成一座塔](./images/27-hei-industry.png)

*配图为示意插画，用于帮助理解本章主题，与实际软件界面无关。*

## 一、行业工作流和通用工作流的区别

| 维度 | 通用工作流 | 行业工作流 |
|-|-|-|
| 输入 | "写一篇活动推文" | "写暑期班招生推文，面向 3-6 岁孩子家长，主打小班教学" |
| 知识 | 模型自带的常识 | 你喂给它的行业资料：话术、合规红线、竞品、季节节奏 |
| 验收 | 读起来通顺 | 符合行业惯例、不踩合规线、懂客户黑话 |
| 壁垒 | 低，人人可复制 | 高——知识库是你一条条喂出来的 |

核心洞察：**AI 不缺通用能力，缺的是你的行业上下文**。行业知识库就是
你给 AI 的"岗前培训"。

## 二、行业知识库：本篇最重要的资产

### 结构模板（照抄即可）

```text
knowledge/【你的行业】/
├── 00-行业黑话表.md      # 行业术语、缩写、客户常说的"行话"
├── 01-合规红线.md        # 什么能说、什么不能说（广告法、行业规定）
├── 02-客户画像.md        # 客户分几类、各自在意什么、决策链
├── 03-竞品档案.md        # 主要竞品、打法、价格带（第 23 章案例二自动更新）
├── 04-季节节奏.md        # 行业日历：旺季、节点、预算周期
├── 05-话术库.md          # 验证过有效的沟通/销售话术
└── 06-案例库.md          # 你自己做成过的项目复盘
```

### 建库提示词（对每份资料跑一次）

```text
读取这份行业资料（materials/xxx.pdf），按我的知识库模板（knowledge/行业模板.md）：
1. 提炼要点，归入对应编号文件（黑话/合规/画像/竞品/节奏/话术）；
2. 每条要点标注来源（文件名+页码）和入库日期；
3. 与库里已有条目冲突时，不要覆盖——列出来让我裁决；
4. 最后输出本次入库摘要：新增几条、改动几条、待裁决几条。
```

### 建库纪律（决定库的生死）

1. **一源一条目**，永远带出处——没有出处的知识三个月后你自己都不敢用；
2. **冲突不覆盖，交给人工裁决**——行业知识的"新旧"往往意味着"政策变了"；
3. **每周维护 30 分钟**，比半年重建一次强一百倍。
